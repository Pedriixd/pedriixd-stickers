Generador de Mapa de Imágenes

Esta herramienta generará un archivo JavaScript con todas las imágenes de tus carpetas para la aplicación PEDRIIXD Stickers.

Instrucciones:

  1. Organiza tus imágenes en carpetas por categoría (mates, computadoras, personajes, etc.)
  2. Selecciona todas esas carpetas o arrastra y suelta todas tus imágenes en el área indicada abajo
  3. Haz clic en "Generar Mapa" para crear el archivo imageMap.js
  4. Descarga el archivo generado y guárdalo en la misma carpeta que index.html

Nota: Este proceso se ejecuta localmente en tu navegador. Ninguna imagen se sube a Internet.
